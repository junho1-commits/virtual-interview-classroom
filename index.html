💡 [필독] 인공지능 가상 면담 학습 시 주의할 점

  • 실제 인물이 아닌 생성형 AI의 가상 역할 수행(Roleplay)입니다: 본 챗봇은 실제 인물의 공개된 인터뷰, 자서전, 언론 보도 일화를 학습한 AI가 가상으로 대화하는 학습용 시뮬레이션입니다.
  • 팩트체크(사실 확인)를 병행해요: AI의 답변은 생생한 일화를 재구성한 것이므로, 연도나 수치 등 구체적인 정보는 백과사전이나 공식 뉴스 기사로 다시 한번 교차 확인(Fact-check)하는 습관을 가져요.
  • 인공지능 앞에서도 면담 예절을 지켜요: 가상 인물과의 대화이지만, 국어 2단원 실습이므로 바른 존댓말과 경청하는 태도로 질문해야 합니다.
  • 개인정보 입력 금지: 집 주소, 전화번호 등 본인의 소중한 개인정보는 절대 채팅창에 입력하지 마세요.

🔑 Google Gemini API 키 설정

📁 [추천] 파일(config.js)에 API 키 영구 저장하기

프로그램 폴더 내 config.js 파일을 메모장으로 열어 GEMINI_API_KEY: "발급받은키" 에 입력해 두면 매번 웹에서 입력할 필요 없이 자동으로 연결됩니다.
* config.js 파일은 .gitignore에 등록되어 있어 깃허브(GitHub)에 절대 올라가지 않으니 안심하세요!

💡 무료 키 발급: Google AI Studio 접속 → [Get API key] 클릭 (AQ... 또는 AIza... 형식 지원)

* config.js 파일에 키가 설정되어 있으면 그 파일의 키가 우선 적용됩니다.
* 파일 수정 없이 브라우저에서 바로 테스트하고 싶을 때 여기에 입력 후 [저장하기]를 누르세요.
