# 6학년 2학기 국어 2단원 [궁금한 점을 해결해요] 실제 인물 가상 면담 챗봇

모덕초등학교 6학년 학생 설문(104명) 결과를 바탕으로 제작된 **초등 국어 면담 실습 전용 가상 챗봇 웹 애플리케이션**입니다.  
학생들이 동경하는 실제 인물(유튜버 허팝, 요리사 이연복, 손흥민, 아이유, 이대우 형사 등)과 **진짜 인생 일화**를 바탕으로 생생한 면담을 나누고, 국어 2단원의 성취기준인 **'질문 3요소(사실·느낌·당부)'**를 충실히 실습할 수 있도록 설계되었습니다.

---

## 🚀 빠른 시작 가이드 (선생님용)

### 1단계: 무료 Gemini API 키 발급받기 (1분 소요, 카드 등록 없음)
1. 인터넷 브라우저로 [Google AI Studio (https://aistudio.google.com/)](https://aistudio.google.com/) 에 접속합니다.
2. 구글 계정으로 로그인합니다.
3. 좌측 상단 또는 화면 중앙의 **[Get API key]** 버튼을 클릭합니다.
4. **[Create API key]**를 클릭하고 생성된 키(최신 키는 **`AQ...`** 로 시작하며, 기존 키는 **`AIza...`** 로 시작합니다)를 복사합니다.

### 2단계: 웹앱 실행 및 API 키 등록
1. 본 폴더의 `index.html` 파일을 더블 클릭하여 크롬/웨일/엣지 브라우저에서 엽니다.
2. 우측 상단의 **[API 키 등록 필요]** 버튼을 누르고 복사한 키(`AQ...`)를 붙여넣은 뒤 **[저장하기]**를 누릅니다.
3. 초록색 불빛과 함께 **'API 키 연결됨'**으로 바뀌면 모든 준비가 완료됩니다!

### 3단계: 학생들에게 간편하게 배포하기 (학생 키 입력 생략)
학생들이 태블릿(웨일북, 아이패드, 크롬북)이나 컴퓨터실에서 사용할 때, 일일이 API 키를 입력할 필요가 없습니다.  
URL 파라미터 기능이 내장되어 있어 다음과 같이 배포하시면 됩니다:

> **배포 주소 예시**:  
> `index.html?key=선생님의API키`  
> *(패들렛, 위두랑, 클래스팅 등에 링크로 게시해 주시면 학생들이 누르자마자 바로 면담을 시작할 수 있습니다.)*

## 🌟 주요 기능 및 교육과정 연계 포인트

### 1. 104명 학생 설문 완벽 반영 15인 실제 인물 라인업
- **미디어·크리에이터**: 허팝 (유튜브 실험 실패와 극복, 나눔 일화)
- **외식·조리**: 이연복 셰프 (후각 상실 극복, 배달원 시절 끈기), 김영모 제과명장 (천연효모 빵 개발 일화)
- **공공·안전**: 이대우 강력계 형사 (잠복근무와 위험 극복 일화), 오영환 전 소방관 (화재 현장 생명 구조 일화)
- **스포츠**: 손흥민 선수 (양발 기본기 수천 번 훈련 일화), 이정후 선수 (아버지 그늘을 극복한 스윙)
- **예술·대중음악**: 아이유 (20번 오디션 탈락과 일기장 작사 일화)
- **생명·동물·보건**: 설채현 수의사 (유기견 마음 열기), 김현아 간호사 (메르스 사명감 편지)
- **전문직·학문**: 정헌택 기장 (돌풍 속 비상 착륙), 박준영 재심 변호사 (약촌오거리 무죄 감동 실화), 김동건 디렉터 (마비노기 코딩 일화), 유현준 건축가 (학교 공간 철학), 심채경 천문학자 (달 탐사 다누리호)
- **원하는 직업 직접 입력**: 목록에 없는 직업을 희망하는 학생을 위해 15년 차 전문가 AI 즉시 생성 지원

### 2. 국어 2단원 핵심 질문 3요소 실시간 체크리스트
- 화면 우측 사이드바에서 학생이 다음 세 가지 질문을 골고루 던졌는지 자동/수동 점검:
  - [x] ① **구체적인 사실에 대한 질문** (하루 일과, 자격, 준비 과정 등)
  - [x] ② **생각이나 느낌에 대한 질문** (가장 보람찬 순간, 위기 극복 감정 등)
  - [x] ③ **앞으로의 계획이나 당부에 대한 질문** (목표, 초등학생에게 전하는 조언 등)

### 3. 교과서 학습지 양식 '면담 정리 보고서' 원클릭 생성 & A4 인쇄
- 대화가 끝난 후 **[📄 면담 완료 및 보고서 작성]** 버튼을 누르면 AI가 대화 내용을 교과서 양식(일시, 면담자, 목적, 질문과 답변 요약, 새롭게 알게 된 점, 느낀 점)으로 깔끔하게 정리해 줍니다.
- **[🖨️ A4 학습지 인쇄]**를 누르면 다른 웹 요소 없이 깨끗한 보고서 학습지만 출력됩니다.
